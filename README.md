# Makaka Pilot для Termux

Команда **`makaka`** проверяет обновления в GitHub, устанавливает зависимости при изменении версии и запускает игру в Chromium без окна. Фарм и прохождение выполняет `makaka-pilot.user.js`.

## Установка на Android

Установи актуальный [Termux из F-Droid или официального GitHub](https://github.com/termux/termux-app#installation). Root и Termux:X11 для этого запуска не нужны. Пакет Chromium берётся из [официального x11-репозитория Termux](https://github.com/termux/termux-packages/tree/master/x11-packages/chromium); графическое окно не открывается.

Вставь в Termux по очереди:

```bash
pkg update -y
pkg install -y git
git clone https://github.com/ViGetTo/makaka-pilot.git "$HOME/makaka-pilot"
bash "$HOME/makaka-pilot/install-termux.sh"
makaka telegram-login
makaka
```

Установщик поставит Node.js, Chromium и зависимости. Chromium занимает заметное место; заранее освободи место для браузера и его кэша. Если папка `~/makaka-pilot` уже существует, повторно клонировать её не нужно.

## Вход с автоматическим обновлением ссылки

В версии **2.9.0** ссылку можно получать прямо в Termux, без кнопки «Открыть в браузере» и компьютера:

1. Открой `@makaka_killer_bot` в Telegram и запусти игру один раз.
2. Подготовь собственные **api_id** и **api_hash** с [my.telegram.org](https://my.telegram.org/apps). [Инструкция Telegram](https://core.telegram.org/api/obtaining_api_id).
3. Останови работающий `makaka` через Ctrl+C. Выполни `makaka telegram-login`.
4. Введи `api_id`, `api_hash`, номер телефона, код от Telegram и пароль 2FA, если Telegram его запросит. Секретные поля вводятся скрыто и не передаются в аргументах команды. Иногда Telegram дополнительно требует подтверждение email; команда поддерживает и этот запрос.
5. Выполни `makaka check` для проверки входа без боя, затем `makaka` для автоматизации.

Код и пароль 2FA не сохраняются. `api_id`, `api_hash` и авторизованная сессия остаются в `~/.local/state/makaka-pilot/telegram.json`, вне репозитория, с правами `600`; каталог закрыт правами `700`. Этот файл даёт доступ к аккаунту: не отправляй его другим людям. Сессию можно отозвать в Telegram → Настройки → Устройства; после отзыва повтори `makaka telegram-login`.

Перед каждым запуском игры, включая `check`, `tune` и `probe`, скрипт получает новую подписанную ссылку штатным методом [messages.requestMainWebView](https://core.telegram.org/method/messages.requestMainWebView); для бота без главного Mini App используется [messages.requestWebView](https://core.telegram.org/method/messages.requestWebView). Для выданного `query_id` поддерживается [prolongWebView](https://core.telegram.org/method/messages.prolongWebView) раз в минуту. Код не запрашивает историю чатов и не отправляет сообщения.

Если игровой API отклонил сессию (`401`, `403` или ошибка `expired`), текущая игровая страница закрывается, ссылка обновляется и автоматизация запускается снова. Указанный лимит сеанса продолжает отсчитываться; перезагрузка его не продлевает. Новый вход с кодом не требуется, пока действует сохранённая сессия Telegram. Если только что выданная ссылка тоже отклонена в течение минуты, повторение прекращается. Новая ссылка должна принадлежать тому же аккаунту; настройки фарма при замене сохраняются.

## Ручной вход по ссылке

`makaka login` сохраняет полную ссылку вида `https://makaka.wivvi.net/#tgWebAppData=...` и переключает запуск на ручное обновление. Ввод скрыт. Если в твоём Telegram нет кнопки открытия Mini App в браузере, используй `makaka telegram-login`; стандартная кнопка «Поделиться» не гарантирует получение данных входа.

Ссылка и настройки сохраняются в `~/.local/state/makaka-pilot/launch.json`, отдельно от Git. На Linux/Android каталог закрыт правами `700`, файлы — `600`. В репозиторий они не отправляются. При другом `XDG_STATE_HOME` путь меняется. Chromium использует временный профиль, который Puppeteer удаляет при штатном закрытии.

В ручном режиме после истечения ссылки нужно повторить `makaka login` со свежей ссылкой. Скрипт получает подписи у Telegram и не подделывает их.

## Команды

| Команда | Действие |
| --- | --- |
| `makaka` | Обновиться с `origin/main` и запустить прохождение волн с фармом бананов при отказах |
| `makaka farm` | Только фарм без покупок и попыток прохождения |
| `makaka config` | Настроить пачку фарма и длительность сеанса |
| `makaka tune` | Сравнить пачки от 1 до 16 врагов по серверному доходу и сохранить лучшую |
| `makaka probe` | Проверить серверную выплату после быстрых убийств, выхода через паузу и перезапуска |
| `makaka bench` | Сравнить текущий фарм с коротким забегом до элитного врага: по пять циклов, сохранить выигрыш от 5% |
| `makaka check` | Проверить загрузку игры без боя и покупок |
| `makaka login` | Сохранить новую ссылку входа |
| `makaka telegram-login` | Один раз войти по api_id/api_hash и включить автоматическое обновление ссылки |
| `makaka status` | Показать последний сохранённый статус с временем проверки |
| `makaka stop` | Запросить остановку работающего запуска |
| `makaka doctor` | Проверить Node.js и путь Chromium |
| `makaka --offline` | Явно запустить установленную версию без проверки GitHub |

Остановка в текущем терминале — **Ctrl+C**. Команды `status` и `stop` работают без проверки GitHub. Последний статус может быть устаревшим, если Android принудительно завершил Termux.

В версии **2.10.0** обычный `makaka` сразу начинает **прохождение волн**. После принятия волны сервером он запускает следующую и продолжает проходить их подряд.

При отказе сервера завершить волну, поражении или отсутствии результата за **90 секунд** автомат выходит через паузу и переключается на **фарм бананов ×8**. Через **три минуты фарма** он заканчивает текущую пачку, ждёт серверного зачёта и снова пробует пройти волну. При успехе продолжает следующие волны подряд; при отказе снова фармит три минуты. Ожидание зачёта текущей пачки может немного сдвинуть проверку.

**Урон покупается всегда, когда хватает полной цены**, во время прохождения и фарма. При большом балансе покупаются несколько уровней последовательно, с паузами между запросами. Пока денег мало, они копятся на урон. В автомате включены обязательные покупки урона и нулевой резерв; прежнее отключение покупок или сохранённый резерв не блокируют это поведение. Покупка считается подтверждённой по новому уровню или урону в ответе сервера.

Прохождение использует режим `survival` ×1 со штатными уроном и скорострельностью и защитой здоровья. Купленное снаряжение определяет фактический урон. Фарм бананов использует прежнюю пачку ×8, генератор и кликер.

По умолчанию сеанс **без ограничения времени**, до Ctrl+C или `makaka stop`. Пороги банка и рекорда его не останавливают. Выбранная пачка сохраняется. Для ограничения времени выполни `makaka config` и укажи минуты; `0` означает работу без конца. Переходы между волнами и фармом не сбрасывают длительность сеанса. `makaka farm` — отдельная команда для чистого фарма без покупок и прохождения. Сброс боя другим окном и ограничения частоты останавливают запуск. Истёкшая игровая сессия обновляется автоматически после настройки входа Telegram.

## Цветная консоль и рейтинг

В Termux показывается обновляемая цветная панель: баланс, доход в минуту, рекорд, текущая волна, локальные и подтверждённые сервером убийства, уровень урона, цена следующего улучшения и время до проверки. Баланс выделен золотым, доход — зелёным, бой — бирюзовым, урон — синим, рейтинг — фиолетовым. Строки подстраиваются под ширину терминала; панель обновляется каждую секунду без потока одинаковых записей.

Раз в минуту читаются два штатных рейтинга: **по волнам** и **по общей добыче бананов**. Показываются твоё место в каждом и три лидера по волнам. В игре рейтинг бананов считается по общей добыче, а не по текущему остатку кошелька. При ошибке рейтинга фарм продолжается, сохранённые места отмечаются как старые. `makaka status` показывает последнюю сохранённую панель с временем проверки.

При перенаправлении вывода в файл панель записывается блоками раз в пять секунд без управляющих кодов терминала. Для отключения цветов: `NO_COLOR=1 makaka`.

## Проверка быстрого перезапуска

Чтобы проверить вопрос «начислит ли сервер бананы, если быстро убить всех и выйти через паузу», останови обычный запуск и выполни:

```bash
makaka stop
# Дождись завершения работающего запуска.
makaka probe
makaka
```

`probe` использует сохранённый вход и выполняет один опыт: записывает серверный баланс, убивает противников в локальном режиме «Максимум» ×8, ставит бой на паузу, получает ответ на штатный отчёт об убийствах и выходит из волны. Затем команда читает `/api/state`, перезапускает ту же волну, ставит её на паузу до новых убийств и ещё раз сверяет серверный баланс. После проверки бой отменяется, автоматизация остаётся остановленной.

В версии **2.10.1** во время этого опыта убраны искусственные задержки отчётов самого Pilot. Запрос завершения волны удерживается: опыт проверяет награду за убийства, без бонуса прохождения. В отчёте сохраняются отдельно число отправленных и зачтённых убийств, HTTP-статус и время ответа. Полный штатный отчёт отправляется до отмены боя; ожидание ограничено восемью секундами. Для `probe` и `tune` запросы кликера, генератора и покупок блокируются в браузере, включая фоновые запросы самой игры. Обычный запуск сохраняет прежнюю механику.

Вывод `Сервер сохранил … бананов` появляется только при положительном приросте, сохранившемся после перезапуска, и настоящем ответе сервера на отчёт обо всех локальных убийствах. Волна, рекорд и снаряжение должны остаться прежними. При частичном зачёте выводится, сколько именно убийств принято. Нулевой прирост с подтверждённым отчётом означает отсутствие выплаты в этом опыте. Отсутствие ответа, изменение баланса при повторной проверке или переход на другую волну дают неоднозначный результат. Один опыт не доказывает устойчивый доход в минуту.

Отчёт сохраняется в `~/.local/state/makaka-pilot/probe.json`. Он содержит баланс, ответы зачёта, снаряжение и численные параметры боя и добычи; ссылки входа и Telegram-сессии в нём нет. Для просмотра:

```bash
cat "${XDG_STATE_HOME:-$HOME/.local/state}/makaka-pilot/probe.json"
```

Живой опыт с действующей сессией для версии 2.10.1 ещё не выполнен: локальные проверки не доказывают выплату настоящего сервера. Не запускай другие окна этого аккаунта во время замера. Разбор ограничения дохода находится в [OPTIMIZATION.md](OPTIMIZATION.md#проверка-цели-100-тысмин-2-ноября-2026).

## Подбор максимального дохода

В версии **2.11.0** добавлен `makaka bench`. Останови текущий запуск через Ctrl+C, затем выполни:

```bash
makaka bench
makaka
```

Сравнение выполняет по пять полных циклов текущего фарма и короткого забега до первого элитного врага. Для короткого забега отчёт отправляется к расчётному времени появления последнего врага пачки. Выход и следующий запуск идут через штатные обработчики игры после настоящего зачёта и успешного ответа на выход. Зависший перезапуск останавливается через 15 секунд. Расчёт появления — гипотеза; сервер может засчитать убийства позже.

Покупки, кликер и генератор на время сравнения отключены. Доход считается по сохранённому серверному балансу и времени всех переходов. При смене волны, снаряжения, настроек или неожиданном изменении баланса замер прерывается. Короткий способ и размер пачки сохраняются только при выигрыше минимум 5%; иначе настройки остаются прежними. Отчёт — `~/.local/state/makaka-pilot/benchmark.json`. После замера автоматизация остановлена; `makaka` запускает обычный автомат с выбранным фармом и попытками прохождения каждые три минуты после отказа.

Сравнение обычно занимает несколько минут, максимум около трёх минут на вариант без учёта закрытия при ошибке. Значение 100 тыс./мин относится к чистому фарму в замере пяти циклов. Общий доход автомата зависит также от попыток прохождения; результат на настоящем телефоне ещё нужно получить. `makaka tune` возвращает классический способ с подбором пачек 1–16.

Если установлена версия 2.5, сначала один раз обнови её командой `git -C "$HOME/makaka-pilot" pull --ff-only`: старый запускатель ещё не знает команды `tune`. В следующих версиях проверка команд выполняется после обновления.

Останови другие запуски этого аккаунта, затем выполни:

```bash
makaka tune
makaka farm
```

`tune` сравнивает **все размеры пачки от 1 до 16 врагов**, по два цикла на каждую. Покупки, генератор и кликер на время замера выключены. Доход считается по изменению серверного баланса и реальному времени, включая переходы. Лучший размер сохраняется в настройках. Подробные результаты остаются в `~/.local/state/makaka-pilot/tuning.json`.

Полный подбор может занять больше десяти минут. Если в процессе поменялись снаряжение, волна или режим, измерение прерывается. После существенных улучшений или перехода на другую волну повтори `makaka tune`. При сбросе боя сервером скрипт останавливается и прекращает повторные отчёты; проверь другие окна и перезагрузи игру.

`makaka farm` использует выбранную пачку и длительность из настроек. На этот запуск он выключает покупки и попытки прохождения. Обычная команда `makaka` запускает автоматический цикл. Подбор `tune` также выполняется без попыток прохождения и покупок.

В версии **2.7.0** исправлено ожидание 17-го убийства, которое сервер мог не засчитывать. Без настроенного размера пачки фармер оставляет двух последних противников. После набора пачки он один раз вызывает штатный отчёт игры раньше обычного двухсекундного таймера и ждёт настоящий ответ. Переходы проверяются каждые 100 мс; анимация ожидания работает с обычной скоростью. Генератор и кликер продолжают работать, пока ожидается зачёт убийств.

Замеры и ограничения записаны в [OPTIMIZATION.md](OPTIMIZATION.md).

## Запуск в фоне

Во время работы вызывается `termux-wake-lock`, при штатной остановке — `termux-wake-unlock`. Разреши Termux работу без ограничения батареи в настройках Android. Держать игровую вкладку в обычном браузере не нужно: отдельный Chromium работает внутри Termux.

Это не гарантирует работу после блокировки экрана: Android и прошивка могут завершать фоновые процессы, особенно при нехватке памяти. [Termux отдельно описывает ограничения Android 12+](https://github.com/termux/termux-app#installation). При остановке системой просто запусти `makaka` снова. Автозапуск после перезагрузки телефона не настроен.

## Экран «ОТКРОЙ В TELEGRAM»

Игра добавляет к запросам управляемого браузера `X-Automation: 1`. В проверенной сессии запрос запуска с этой меткой получил **403**, без неё — **200**. Вариант для Termux убирает эту метку до загрузки игры двумя способами: через скрипт страницы и через перехват запросов Chromium. Остальные заголовки, в том числе подпись Telegram, сохраняются. Перехват ограничен API `https://makaka.wivvi.net`.

Ещё одна проверенная причина отказа — название `HeadlessChrome` в User-Agent браузера без окна. Запускатель заменяет только эту метку на `Chrome`, сохраняя настоящую версию браузера и платформу. В отдельном новом браузере на ПК до этой правки запуск возвращал 403, после неё игра загрузилась с 200.

Обновление защиты игры может потребовать изменений. В режиме Telegram истёкшая ссылка обновляется автоматически; отклонение свежей ссылки останавливает запуск. Бесконечного подбора авторизации нет.

## Проверки и результаты

- На ПК подтверждён серверный рекорд **60** с уровнем урона 25 и крита 16.
- На 64-й волне в версии 2.7.0 подтверждено около **49,5 тыс. бананов/мин** на пяти циклах пачки из 15 врагов, без генератора и кликера. Результаты зависят от снаряжения, волны и задержки сети.
- `npm test` проверяет механику фарма, подбор пачки, ссылки входа, область перехвата и хранение настроек. `bash test/updater.sh` проверяет обновление, сохранение местных изменений и отказ сети.
- Для 2.8.0 локально проверены трёхминутный цикл, возврат при отказе и тайм-ауте, переход после принятой волны, отмена старого завершения, одна покупка с резервом и проверка выплат с моделируемыми ответами. Эти результаты не являются опытом на настоящем сервере.
- Для 2.9.0 проверены скрытые запросы входа, сериализация запроса настоящим SDK, сохранение сессии с закрытыми правами, проверка аккаунта и повторное получение ссылки. Полный `run.mjs` в Chromium восстановил фарм после имитируемого `401`, сохранил оставшуюся длительность и выполнил `makaka stop`. Живой вход в Telegram и Android/Termux в этой среде не проверены.
- В Chromium без окна на ПК проверены настоящий вход, ответ запуска 200, загрузка движка и скрипта. Бой при этой проверке не запускался.
