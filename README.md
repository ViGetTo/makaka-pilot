# Makaka Pilot для Termux

Команда **`makaka`** проверяет обновления в GitHub, устанавливает зависимости при изменении версии и запускает игру в Chromium без окна. Фарм и прохождение выполняет `makaka-pilot.user.js`.

## Установка на Android

Установи актуальный [Termux из F-Droid или официального GitHub](https://github.com/termux/termux-app#installation). Root и Termux:X11 для этого запуска не нужны. Пакет Chromium берётся из [официального x11-репозитория Termux](https://github.com/termux/termux-packages/tree/master/x11-packages/chromium); графическое окно не открывается.

Вставь в Termux по очереди:

```bash
pkg update -y
pkg install -y git
git clone https://github.com/ViGetTo/makaka-pilot.git "$HOME/makaka-pilot"
bash "$HOME/makaka-pilot/install-termux.sh"
makaka login
makaka
```

Установщик поставит Node.js, Chromium и зависимости. Chromium занимает заметное место; заранее освободи место для браузера и его кэша. Если папка `~/makaka-pilot` уже существует, повторно клонировать её не нужно.

## Первый вход

1. Открой `@makaka_killer_bot` в Telegram и запусти игру.
2. Получи полную ссылку **открытого окна игры**: `https://makaka.wivvi.net/#tgWebAppData=...`. Если в меню мини-приложения доступно открытие в браузере, открой и скопируй адрес целиком. Нужна ссылка со всеми параметрами после `#`, как та, которую ты присылал в чате. Ссылка только на бота или просто на сайт не подходит.
3. Выполни `makaka login` и вставь ссылку. Ввод скрыт, ссылка не попадает в историю команд.
4. Выполни `makaka check` для проверки входа без запуска боя. Затем `makaka` для фарма.

Ссылка и настройки сохраняются в `~/.local/state/makaka-pilot/launch.json`, отдельно от Git. На Linux/Android каталог закрыт правами `700`, файлы — `600`. В репозиторий они не отправляются. При другом `XDG_STATE_HOME` путь меняется. Chromium использует временный профиль, который Puppeteer удаляет при штатном закрытии.

Telegram может ограничивать срок сессии. Если сервер отклонил вход, снова открой игру в Telegram и повтори `makaka login` со свежей ссылкой. Скрипт не подделывает подпись Telegram.

## Команды

| Команда | Действие |
| --- | --- |
| `makaka` | Обновиться с `origin/main` и запустить автомат: фарм и попытки волн |
| `makaka farm` | Только фарм без покупок и попыток прохождения |
| `makaka config` | Настроить резерв, пачку, длительность и покупку улучшений |
| `makaka tune` | Сравнить пачки от 1 до 16 врагов по серверному доходу и сохранить лучшую |
| `makaka probe` | Проверить серверную выплату после быстрых убийств, выхода через паузу и перезапуска |
| `makaka check` | Проверить загрузку игры без боя и покупок |
| `makaka login` | Сохранить новую ссылку входа |
| `makaka status` | Показать последний сохранённый статус с временем проверки |
| `makaka stop` | Запросить остановку работающего запуска |
| `makaka doctor` | Проверить Node.js и путь Chromium |
| `makaka --offline` | Явно запустить установленную версию без проверки GitHub |

Остановка в текущем терминале — **Ctrl+C**. Команды `status` и `stop` работают без проверки GitHub. Последний статус может быть устаревшим, если Android принудительно завершил Termux.

В версии **2.8.0** обычный `makaka` всегда начинает с **фармера ×8**, сбора генератора и кликера. После **трёх минут** он заканчивает текущую пачку, дожидается серверного зачёта, выходит из боя и пробует пройти **одну волну** в режиме `paced` ×1. Перед попыткой покупается **не больше одного** доступного боевого улучшения с учётом резерва. Покупки можно выключить через `makaka config`.

При первом отказе завершения `too_fast`, поражении или отсутствии результата за **90 секунд** автомат выходит через паузу и возвращается к фарму. При принятии волны сервером он фармит следующую волну. Следующая попытка назначается через три минуты от начала предыдущей; завершение текущей пачки и сетевые задержки могут сдвинуть запуск. Переходы не выключают автоматизацию и не сбрасывают длительность сеанса.

По умолчанию сеанс **без ограничения времени**, до Ctrl+C или `makaka stop`. Пороги миллиона бананов и 60-й волны больше не останавливают обычный запуск. Старые настройки `farmer`/`paced` переходят на этот режим автоматически; выбранная пачка и резерв сохраняются. Для ограничения времени выполни `makaka config` и укажи минуты; `0` означает работу без конца. `makaka farm` оставляет только фарм. Ошибки входа, сброс боя другим окном и ограничения частоты по-прежнему останавливают запуск.

## Проверка быстрого перезапуска

Чтобы проверить вопрос «начислит ли сервер бананы, если быстро убить всех и выйти через паузу», останови обычный запуск и выполни:

```bash
makaka stop
# Дождись завершения работающего запуска.
makaka probe
makaka
```

`probe` использует сохранённый вход и выполняет один опыт: записывает серверный баланс, убивает противников в локальном режиме «Максимум» ×8, сразу ставит бой на паузу и вызывает штатный выход игры. При выходе сама игра отправляет оставшийся отчёт об убийствах. Затем команда читает `/api/state`, перезапускает ту же волну, ставит её на паузу до новых убийств и ещё раз сверяет серверный баланс. Кликер, сбор и покупки выключены; после проверки бой отменяется, автоматизация остаётся остановленной.

Вывод `Сервер сохранил … бананов` появляется только при положительном приросте, сохранившемся после перезапуска, без изменения волны, рекорда и снаряжения. Это подтверждает награду за убийства; бонус прохождения проверкой не подтверждается. Нулевой прирост означает отсутствие выплаты в этом опыте. Изменение баланса при повторной проверке или переход на другую волну даёт неоднозначный результат. Отчёт сохраняется в `~/.local/state/makaka-pilot/probe.json`.

Живой опыт с действующей сессией в версии 2.8.0 ещё не выполнен: добавление команды и локальные проверки не доказывают выплату настоящего сервера. Не запускай другие окна этого аккаунта во время замера.

## Подбор максимального дохода

Если установлена версия 2.5, сначала один раз обнови её командой `git -C "$HOME/makaka-pilot" pull --ff-only`: старый запускатель ещё не знает команды `tune`. В следующих версиях проверка команд выполняется после обновления.

Останови другие запуски этого аккаунта, затем выполни:

```bash
makaka tune
makaka farm
```

`tune` сравнивает **все размеры пачки от 1 до 16 врагов**, по два цикла на каждую. Покупки, генератор и кликер на время замера выключены. Доход считается по изменению серверного баланса и реальному времени, включая переходы. Лучший размер сохраняется в настройках. Подробные результаты остаются в `~/.local/state/makaka-pilot/tuning.json`.

Полный подбор может занять больше десяти минут. Если в процессе поменялись снаряжение, волна или режим, измерение прерывается. После существенных улучшений или перехода на другую волну повтори `makaka tune`. При сбросе боя сервером скрипт останавливается и прекращает повторные отчёты; проверь другие окна и перезагрузи игру.

`makaka farm` использует выбранную пачку и длительность из настроек. На этот запуск он выключает покупки и попытки прохождения. Обычная команда `makaka` запускает автоматический цикл. Подбор `tune` также выполняется без попыток прохождения и покупок.

В версии **2.7.0** исправлено ожидание 17-го убийства, которое сервер мог не засчитывать. Без настроенного размера пачки фармер оставляет двух последних противников. После набора пачки он один раз вызывает штатный отчёт игры раньше обычного двухсекундного таймера и ждёт настоящий ответ. Переходы проверяются каждые 100 мс; анимация ожидания работает с обычной скоростью. Генератор и кликер продолжают работать, пока ожидается зачёт убийств.

Замеры и ограничения записаны в [OPTIMIZATION.md](OPTIMIZATION.md).

## Запуск в фоне

Во время работы вызывается `termux-wake-lock`, при штатной остановке — `termux-wake-unlock`. Разреши Termux работу без ограничения батареи в настройках Android. Держать игровую вкладку в обычном браузере не нужно: отдельный Chromium работает внутри Termux.

Это не гарантирует работу после блокировки экрана: Android и прошивка могут завершать фоновые процессы, особенно при нехватке памяти. [Termux отдельно описывает ограничения Android 12+](https://github.com/termux/termux-app#installation). При остановке системой просто запусти `makaka` снова. Автозапуск после перезагрузки телефона не настроен.

## Экран «ОТКРОЙ В TELEGRAM»

Игра добавляет к запросам управляемого браузера `X-Automation: 1`. В проверенной сессии запрос запуска с этой меткой получил **403**, без неё — **200**. Вариант для Termux убирает эту метку до загрузки игры двумя способами: через скрипт страницы и через перехват запросов Chromium. Остальные заголовки, в том числе подпись Telegram, сохраняются. Перехват ограничен API `https://makaka.wivvi.net`.

Ещё одна проверенная причина отказа — название `HeadlessChrome` в User-Agent браузера без окна. Запускатель заменяет только эту метку на `Chrome`, сохраняя настоящую версию браузера и платформу. В отдельном новом браузере на ПК до этой правки запуск возвращал 403, после неё игра загрузилась с 200.

Обновление защиты игры или истёкшая сессия могут потребовать изменений. Ошибки входа останавливают запуск; бесконечного подбора авторизации нет.

## Проверки и результаты

- На ПК подтверждён серверный рекорд **60** с уровнем урона 25 и крита 16.
- На 64-й волне в версии 2.7.0 подтверждено около **49,5 тыс. бананов/мин** на пяти циклах пачки из 15 врагов, без генератора и кликера. Результаты зависят от снаряжения, волны и задержки сети.
- `npm test` проверяет механику фарма, подбор пачки, ссылки входа, область перехвата и хранение настроек. `bash test/updater.sh` проверяет обновление, сохранение местных изменений и отказ сети.
- Для 2.8.0 локально проверены трёхминутный цикл, возврат при отказе и тайм-ауте, переход после принятой волны, отмена старого завершения, одна покупка с резервом и проверка выплат с моделируемыми ответами. Эти результаты не являются опытом на настоящем сервере.
- В Chromium без окна на ПК проверены настоящий вход, ответ запуска 200, загрузка движка и скрипта. Бой при этой проверке не запускался.
- Проверки в Termux на настоящем телефоне ещё не выполнены. Поддержка Android основана на официальном пакете Chromium и `puppeteer-core`, который умеет работать с [явно заданным браузером](https://pptr.dev/guides/installation#puppeteer-core).
